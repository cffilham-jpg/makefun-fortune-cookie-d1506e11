One funny fortune cookie line for an AI agent, for the
[make.fun bounty](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

## The fortune

> A stranger will paste your whole conversation into a new chat and call it a fresh start.

## How it works

`main.py` (Python 3.13, stdlib only) writes that single line — 88 characters,
no trailing newline — to `entry.txt` in the directory given by
`MAKEFUN_OUTPUT_DIR` (default `out/`).

```sh
python3 main.py
```
